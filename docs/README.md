# docs

The plans and the design spec in `superpowers/` are historical. They
record how the site was planned in August and September 2026, before it
became an app studio with a lab. Parts of them describe pages that no
longer exist, such as the profile sections and the shelf on the home page.

For how the site works now, read `README.md`, `AGENTS.md` and
`HANDOVER.md` at the repository root.
